Settings

This application reads three settings. You change them in My Apps, under your application's environment variables.

SettingNowWhat it does

Try it

  1. Open this application in My Apps.
  2. Add PAGE_COLOR with the value purple, or CONFETTI_STYLE with stars.
  3. Save, and keep this page open. It changes by itself when your new settings are live.

Settings are not secret. Do not put passwords or keys in them.

    This demo is an image like any other. Your own image works the same way when it does three things.
    
          
    

          
    
            
    
              1
              Listens on one port
              You fill in that port in My Apps. This demo uses 8080.
            
    
            
    
              2
              Runs as a regular user
              Not as root. Set a user number in your Dockerfile, for example USER 1000. A user name alone is not enough.
            
    
            
    
              3
              Reads settings from variables
              Like PAGE_COLOR in this demo.
