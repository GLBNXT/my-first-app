    Deploy your own application
    
      
    This demo is an image like any other. Your own image works the same way when it does three things:
    
      
      
        
    • Listens on one port. You fill in that port in My Apps. This demo uses 8080.
      • 
        
    • Runs as a regular user, not as root. Set a user number in your Dockerfile, for example USER 1000. A user name alone is not enough.
      • 
        
    • Reads its settings from environment variables. Like PAGE_COLOR on this page.
